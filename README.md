## Projects

### 1. Breast Cancer Classification Using Machine Learning

**Folder:** `breast-cancer-ml`

**Overview**

This project explores how machine learning can help classify breast tumours as benign or malignant using diagnostic measurements.

I used the Breast Cancer Wisconsin Diagnostic dataset to develop and compare different machine learning models, investigating their effectiveness in identifying cancer.

**Methods and Technologies**
- Python, Pandas, NumPy and Scikit-learn
- Logistic Regression
- Support Vector Machine (SVM)
- Random Forest
- Data preprocessing and model evaluation
- Accuracy, F1-score and ROC-AUC

**Results**

Three classification algorithms were evaluated, with Random Forest achieving the strongest overall results:

| Metric | Result |
|---|---|
| Accuracy | 97.4% |
| F1-Score | 0.963 |
| ROC-AUC | 0.994 |

**What I Learned**

This project strengthened my understanding of supervised learning, model comparison, classification metrics and the potential applications of artificial intelligence in healthcare.

### 2. Facial Emotion Recognition Using Deep Learning

**Folder:** `face-emotion-recognition`

**Overview**

This project focuses on using artificial intelligence to recognise human emotions from facial expressions.

I explored both supervised and unsupervised learning techniques to understand how facial features can be analysed and classified.

The supervised learning component uses the FER2013 dataset, which contains facial images representing seven emotional categories.

**Methods and Technologies**
- Python
- TensorFlow and Keras
- Convolutional Neural Networks (CNNs)
- OpenCV
- NumPy and Pandas
- Image preprocessing and data augmentation
- Unsupervised clustering and feature analysis

**Implementation**

The project involved:
- Preparing and normalising facial image data
- Training a CNN to classify facial expressions
- Applying data augmentation to improve training
- Evaluating predictions using classification metrics
- Exploring patterns in facial features through unsupervised learning

**What I Learned**

I developed a stronger understanding of deep learning, image classification, computer vision and the challenges of interpreting human expressions through AI.

### 3. Face Recognition System

**Folder:** `face-recognition`

**Overview**

This project demonstrates how artificial intelligence and computer vision can be used to detect and recognise known individuals from images and video.

I developed a Python-based face recognition system using facial encodings and similarity comparisons.

**Methods and Technologies**
- Python
- OpenCV
- `face_recognition` library
- Facial feature encoding
- Face detection and matching
- Video frame processing

**Implementation**

The system:
- Processes reference images of known individuals
- Generates facial encodings to represent their facial features
- Detects faces in video frames
- Compares detected faces against stored encodings
- Displays recognised names alongside detected faces

**What I Learned**

This project helped me understand facial recognition, feature extraction, image processing and the practical applications and limitations of biometric identification systems.

### 4. Football Player Sentiment Analysis

**Folder:** `football-player-sentiment-analysis`

**Overview**

This project explores how natural language processing and machine learning can be used to analyse opinions and discussions about football players.

I worked with different data sources, including online discussions and football-related datasets, to investigate public sentiment and patterns in player-related information.

**Methods and Technologies**
- Python
- Pandas and NumPy
- Scikit-learn
- NLTK and spaCy
- Reddit data collection using PRAW
- BeautifulSoup
- Matplotlib and Seaborn
- Text cleaning and sentiment analysis
- Machine learning classification

**Implementation**

The project involved:
- Collecting and preparing text-based data
- Cleaning and preprocessing unstructured text
- Exploring sentiment in football-related discussions
- Applying machine learning techniques to classify text
- Comparing modelling approaches
- Creating visualisations to interpret findings
- Exploring football player statistics and related data

**What I Learned**

This project improved my understanding of natural language processing, working with unstructured data, sentiment analysis and the challenges of extracting meaningful insights from online discussions.
